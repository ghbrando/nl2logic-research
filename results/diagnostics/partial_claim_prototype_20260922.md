# FM 2-0 partial-claim development prototype — 22 September 2026

The [development packet](../../data/benchmarks/fm2-0/development_partial_claims_20260922.json) contains one AI-reviewed, source-derived partial claim from FM 2-0 (01 October 2023), paragraph 1-93, printed page 1-21, PDF page 37. The quoted source says biometrics is a process of recognizing an individual. The proposed formula is `BiometricsProcess subclass-of Process`, compiled to `(subclass BiometricsProcess Process)`. The distinct class name limits the assertion to the process sense: the same paragraph also uses *biometrics* for characteristics of an individual. The full definition of recognition and the measurable characteristics are omitted, so coverage is **partial**, not whole-sentence.

The packet separately declares `(instance BiometricsProcess Class)`. That declaration adds a symbol for compilation; it does not place `(subclass BiometricsProcess Process)` into the background ontology. The assertion is absent from `doctrine_domain.kif`. The [packet validator](../../scripts/validate_claim_packet.py) verified the pinned PDF SHA-256, the exact span in the paragraph excerpt and extracted PDF page, CNL syntax and vocabulary, SUMO relation argument kinds, exact compiled KIF, and that the assertion is not a doctrine-domain axiom. Negative tests confirm that invented spans, declaration/claim conflation, and KIF changes fail. The full test suite passed: 979 tests, one skipped.

This is **one exploratory development example, not a new gold benchmark or evidence of model accuracy**. The positive is deliberately simple and partly analytic; it establishes that a source claim can be represented without preloading that exact assertion. It does not show that the representation covers the richer doctrine in the sentence, that other passages yield safe claims, or that the model can predict them. The validator cannot decide entailment and does not yet check every upstream SUMO axiom. No GPU job was started.

Next, expand the development packet with several distinct nontrivial claims and explicit abstentions, resolve whether the ontology can express each without losing conditions, then freeze a separate, unseen source packet for evaluation. The inference path also needs a controlled way to receive approved term declarations before any model comparison. Training should wait until a useful source-backed positive set exists.
