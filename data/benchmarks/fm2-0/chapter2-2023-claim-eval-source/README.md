# FM 2-0 chapter 2 claim evaluation source selection

This directory freezes **source selection only**: all 29 numbered chapter 2 paragraphs on PDF pages 45–52 for which the existing `page_candidates` extractor found a first sentence of at least six words. Selection used no gold labels, model predictions, or manual cherry-picking. [manifest.json](manifest.json) pins the PDF SHA-256 and rule. `source_pages.jsonl` preserves the extracted page text; `selected_passages.jsonl` holds paragraph excerpts and provenance. First sentences had no exact normalized overlap with the existing FM 2-0 seed or chapter 1 candidate files.

The selected source rows remain unchanged and `source_first_sentence` is only an extraction aid, not the scoring unit. The separate [AI-reviewed label packet](ai_reviewed_claims_20260923.json) records exact source spans, one partial positive, and 28 explicit abstentions under [CLAIM_CONTRACT.md](../../../../docs/CLAIM_CONTRACT.md). [review_manifest.json](review_manifest.json) pins its hash before any target NL2Logic model query. These are provisional AI labels, not expert gold. With only one positive, the packet cannot provide a stable positive-recall estimate.

Some excerpts end at a PDF page break or include surrounding layout text; each label's span was checked against the preserved page text and PDF extraction. No target-model query or training job was run while preparing these labels.
